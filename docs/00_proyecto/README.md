# Contexto del proyecto (leer primero)

Documentos finales que sirven de base para trabajar, sea con un agente en el repo o con una IA web:
- `Enunciado.md`: qué pide el docente (fuente de verdad n.º 1).
- `Plan_Fases.md`: plan por etapas, líneas base, mapeo a entregables.
- `Metodologia_Trabajo.md`: roles, reparto y cómo se usa el agente.
- `Guia_Git.md`: cómo clonar, ramas, commits y PR.
- `Plan_Evidencias.md`: qué evidencias se toman y cuándo.
- `../07_configuracion/Convencion_IDs.md`: IDs, nombres y rangos por persona.
- `../01_sistema/Ficha_SAMed_v1.md`: el sistema, roles y procesos.
- `Plantilla_Prompt_Agente.md`: plantilla de prompt.

Nota: algunas rutas de estos documentos (`02_Equipo`, `00_Gobernanza`) se refieren a la carpeta de coordinación del líder, que no está en el repo; lo que importa para trabajar está en este repositorio.
